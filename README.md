# Samyuktha G - React Portfolio

A modern React/Vite version of the original portfolio.

## Requirements

- Node.js installed
- VS Code recommended

## Run the project

Open this folder in VS Code and run:

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite, normally:

http://localhost:5173

## Add your profile photo

Replace:

`public/photo.jpg`

with your own photo using the same filename.

## Add favicon

Replace:

`public/favicon.png`

with your preferred favicon.

## Customize

Main files:

- `src/App.jsx` - portfolio content/components
- `src/App.css` - complete styling
- `public/photo.jpg` - profile image
